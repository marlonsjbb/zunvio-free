# Fixture "inconclusivo" (demonstração)

Código limpo, sem segredo e sem vulnerabilidade. A análise é executada **sem** a
evidência obrigatória de funcionamento, demonstrando o terceiro estado canônico:

**INCONCLUSIVO** — não há bloqueador material comprovado (não é NÃO PUBLICAR),
mas também não há prova de atendimento dos portões obrigatórios (não é PUBLICAR).
